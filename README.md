# ORBIYOS - 汎用業務支援システム

解体業・自動車整備業向けの業務管理システム

## 機能

- 📅 作業者別カレンダー表示
- 🚗 車両登録・管理
- 📋 作業割当・ステータス管理
- 🎤 音声入力による作業記録
- 📥 CSVデータインポート
- 🔐 作業者ログイン/ログアウト
- 📱 タブレット・スマホ対応

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# 本番ビルド
npm run build
npm start
```

## 起動後

ブラウザで <http://localhost:3000> にアクセス

### ログイン

作業者一覧から選択してログインします。

### CSVインポート

車両データをCSVファイルから一括登録できます。

**対応フォーマット:**

```csv
ナンバー,メーカー,車名,型式,年式,色,備考
品川500あ1234,トヨタ,プリウス,ZVW30,2020,ホワイト,備考
```

## 技術スタック

- Next.js 16 (App Router)
- TypeScript
- SQLite (better-sqlite3)
- Web Speech API (音声入力)
