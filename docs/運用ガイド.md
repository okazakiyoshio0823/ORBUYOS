# ORBIYOS 運用ガイド

## システム管理者向け

---

## 1. システム構成

```
orbiyos/
├── src/
│   ├── app/           # ページ・APIルート
│   ├── components/    # UIコンポーネント
│   ├── lib/           # データベース操作
│   └── types/         # TypeScript型定義
├── database/
│   └── schema.sql     # DBスキーマ
├── data/
│   └── orbiyos.db     # SQLiteデータベース（自動生成）
└── docs/              # ドキュメント
```

---

## 2. データベース

### 場所

`data/orbiyos.db` （初回起動時に自動作成）

### バックアップ

```bash
# Windows
copy data\orbiyos.db data\orbiyos_backup_%date%.db

# 定期バックアップ（タスクスケジューラ推奨）
```

### リセット

```bash
# データベースを削除して再起動
del data\orbiyos.db
npm run dev
# → /api/init が自動でサンプルデータを投入
```

## 3. 作業者の追加

### 方法1: API経由

```bash
curl -X POST http://localhost:3000/api/workers \
  -H "Content-Type: application/json" \
  -d '{"name":"新しい作業者","role":"worker","industry":"demolition"}'
```

### 方法2: データベース直接編集

```sql
INSERT INTO workers (name, role, industry) 
VALUES ('新しい作業者', 'worker', 'demolition');
```

## 4. 本番環境デプロイ

### Vercelへのデプロイ

```bash
# Vercel CLIインストール
npm i -g vercel

# デプロイ
vercel

# 本番デプロイ
vercel --prod
```

### 注意事項

- SQLiteはVercelのサーバーレス環境では永続化されません
- 本番環境では PostgreSQL や Turso への移行を推奨

## 5. ローカルネットワーク共有

### 現場タブレットからアクセス

1. PCのIPアドレスを確認

   ```bash
   ipconfig
   # IPv4 アドレス: 192.168.x.x
   ```

2. タブレットのブラウザで `http://192.168.x.x:3000` にアクセス

3. ファイアウォールでポート3000を許可
   - Windows Defender → 詳細設定 → 受信の規則 → 新しい規則
   - ポート → TCP → 3000 → 許可

## 6. トラブルシューティング

### ポート3000が使用中

```bash
# 別ポートで起動
npm run dev -- -p 3001
```

### データベースエラー

```bash
# node_modulesを再インストール
rd /s /q node_modules
npm install
```

### 音声入力が動かない

- Chrome/Edge推奨（SafariはWeb Speech API非対応）
- HTTPS or localhost のみ動作
