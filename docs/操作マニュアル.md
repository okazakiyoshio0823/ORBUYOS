## 1. システム起動

### PCで起動

```bash
cd orbiyos
npm run dev
```

ブラウザで `http://localhost:3000` にアクセス

### タブレット・スマホからアクセス

同じネットワーク内のデバイスから `http://[PCのIPアドレス]:3000` にアクセス

---

## 2. ログイン

1. ログイン画面が表示されます
2. 自分の名前をタップして選択
3. 「ログイン」ボタンをタップ

> 💡 作業者は業種別（解体業/整備業）にグループ化されています

---

## 3. ダッシュボード操作

### 業種切り替え

- 画面上部の「🔧 解体業」「🚗 整備業」ボタンで切り替え

### 日付ナビゲーション

- ◀ ▶ ボタンで前日/翌日に移動
- 「今日」ボタンで今日に戻る

### 統計表示

- 画面上部に当日の入庫台数、部品/作業予定、完了数を表示

---

## 4. 車両登録

1. 画面下部のアクションバーで「🚗 車両登録」をタップ
2. 必要事項を入力:
   - ナンバープレート（例: 品川 500 あ 1234）
   - メーカー（ドロップダウンから選択）
   - 車名、型式、年式、色
   - 備考（任意）
3. 「登録」ボタンをタップ

---

## 5. 作業割当

1. アクションバーで「📋 部品割当」（または「入庫受付」）をタップ
2. 作業者を選択
3. 対象車両を選択
4. 部品/サービスを選択
5. 作業開始時間と予定時間を入力
6. 「割当」ボタンをタップ

---

## 6. 作業ステータス管理

### 作業詳細を開く

カレンダー上の作業ブロックをタップ

### ステータス変更

- **▶ 作業開始**: 未着手 → 作業中
- **⏸ 中断**: 作業中 → 中断
- **✅ 完了**: 作業中 → 完了
- **▶ 再開**: 中断 → 作業中

### 色分け

| 色 | ステータス |
|----|----------|
| 各色鮮明 | 作業中 |
| 緑（薄） | 完了 |
| グレー | 未着手 |
| オレンジ | 中断 |

---

## 7. 音声入力

1. アクションバーで「🎤 音声入力」をタップ
2. 中央のマイクボタンをタップして話す
3. コマンドが認識されると自動で実行

### コマンド例

| 発話 | 動作 |
|------|------|
| 「9時 開始」 | 9:00の作業を開始 |
| 「完了」 | 作業中のタスクを完了 |
| 「中断」 | 作業を一時停止 |
| 「メモ ○○」 | 備考を追加 |

---

## 8. CSVインポート

1. アクションバーで「📥 CSVインポート」をタップ
2. 「ファイルを選択」をタップ
3. CSVファイルを選択
4. 「インポート実行」をタップ

### CSVフォーマット

```csv
ナンバー,メーカー,車名,型式,年式,色,備考
品川500あ1234,トヨタ,プリウス,ZVW30,2020,ホワイト,エンジン取り外し済
```

> 💡 英語カラム名（plateNumber, maker等）にも対応

---

## 9. ログアウト

1. 画面右上の「ログアウト」ボタンをタップ
2. ログイン画面に戻ります

---

## トラブルシューティング

### 音声入力が動かない

- ブラウザがマイクへのアクセスを許可しているか確認
- HTTPS接続または localhost でのみ動作

### データが保存されない

- ブラウザをリロードして再度ログイン
- 開発サーバーが起動しているか確認

### タブレットから接続できない

- 同じWi-Fiネットワークに接続されているか確認
- PCのファイアウォール設定を確認
