ORBIYOS

汎用業務支援システム

解体業・自動車整備業向けの次世代業務管理システム。
作業の可視化と効率化を実現します。

🚀 今すぐ始める 📚 ドキュメントを見る

主要機能

📅

作業者別カレンダー

複数の作業者のスケジュールを一目で把握。タイムライン形式で作業の進捗をリアルタイムに確認できます。

🚗

車両登録・管理

ナンバープレート、メーカー、車名、型式などの詳細情報を簡単に登録・検索。車両情報を一元管理できます。

📋

作業割当・ステータス管理

作業の割り当てから完了まで、ステータスを色分けして視覚的に管理。未着手・作業中・中断・完了を一目で判別できます。

🎤

音声入力対応

Web Speech APIを活用した音声コマンド入力。手を使わずに作業開始・完了・メモ追加が可能です。

📥

CSVインポート

既存の車両データをCSVファイルから一括登録。日本語・英語カラム名の両方に対応しています。

🔐

作業者認証

作業者ごとにログイン管理。業種別（解体業/整備業）にグループ化され、適切な権限で安全に運用できます。

📱

マルチデバイス対応

タブレット・スマートフォンでも快適に操作可能。現場での作業記録もスムーズに行えます。

📊

統計・レポート

日次の入庫台数、作業予定、完了数をダッシュボードで表示。業務の進捗を数値で把握できます。

技術スタック

⚛️ Next.js 16 📘 TypeScript ⚡ React 19 🗄️ SQLite 🎤 Web Speech API 🎨 CSS Modules 📱 Responsive Design

セットアップ

1

リポジトリをクローン

プロジェクトをローカルにダウンロードします。

git clone https://github.com/yourusername/orbiyos.git
cd orbiyos
2

依存関係をインストール

必要なパッケージをインストールします。

npm install
3

開発サーバーを起動

ローカル環境で動作確認します。

npm run dev
4

ブラウザでアクセス

http://localhost:3000 にアクセスして、ログイン画面から作業者を選択してログインします。

💡 タブレット・スマホからアクセス

同じWi-Fiネットワーク内のデバイスからアクセスできます。

# PCのIPアドレスを確認
ipconfig

# タブレットのブラウザで以下にアクセス
http://[PCのIPアドレス]:3000
