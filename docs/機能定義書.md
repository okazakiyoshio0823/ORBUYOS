# ORBIYOS 機能定義書

**バージョン**: 1.0  
**最終更新**: 2026年2月15日

---

## 概要

ORBIYOSは、解体業・自動車整備業向けの作業管理システムです。作業者別のカレンダー表示、リアルタイムなステータス管理、音声入力による記録を実現します。

---

## 主要機能一覧

### 1. 認証・ログイン

- **機能**: 作業者名を選択してログイン
- **業種別表示**: 解体業 / 整備業でグループ化
- **認証方式**: パスワード不要のシンプル認証

### 2. ダッシュボード

- **カレンダー表示**: 作業者別タイムライン（8:00〜18:00）
- **業種切替**: 🔧解体業 / 🚗整備業
- **日付ナビゲーション**: 前日/翌日/今日へ移動
- **統計表示**: 入庫台数、予定数、完了数

### 3. 車両管理

#### 3.1 車両登録

- 手動入力: ナンバー、メーカー、車名、型式、年式、色
- CSVインポート: 一括登録機能

#### 3.2 CSVフォーマット

```csv
ナンバー,メーカー,車名,型式,年式,色,備考
品川500あ1234,トヨタ,プリウス,ZVW30,2020,ホワイト,備考
```

### 4. 作業管理

#### 4.1 作業割当

- 作業者・車両・部品/メニュー選択
- 開始時刻・予定時間入力
- 学習した平均時間の自動提案

#### 4.2 ステータス管理

| ステータス | 操作 | 色 |
|----------|------|-----|
| 未着手 | ▶ 作業開始 | グレー |
| 作業中 | ✅ 完了 / ⏸ 中断 | 各色 |
| 完了 | - | 薄緑 |
| 中断 | ▶ 再開 | 薄オレンジ |

#### 4.3 実績記録

- 開始時刻・終了時刻の自動記録
- 実績時間の自動計算
- 過去実績の学習と平均化

### 5. 音声入力

#### 5.1 対応コマンド

| 発話 | 動作 |
|-----|------|
| 「9時 開始」 | 9:00の作業を開始 |
| 「完了」 | 作業完了 |
| 「中断」 | 作業中断 |
| 「再開」 | 作業再開 |
| 「メモ ○○」 | 備考追加 |

#### 5.2 技術仕様

- Web Speech API（SpeechRecognition）
- 言語: 日本語（ja-JP）
- 要件: HTTPS or localhost

### 6. マスタ管理

#### 6.1 部品マスタ（解体業）

- エンジン、ミッション、ドア、ライト等
- 初期データ: 18種類

#### 6.2 整備メニューマスタ（整備業）

- 車検、点検、オイル交換、修理等
- 初期データ: 10種類
- 各メニューに色を設定可能

### 7. カレンダー機能

#### 7.1 表示形式

- 横軸: 時間帯（8:00〜18:00）
- 縦軸: 作業者
- 各作業: 色付きブロック

#### 7.2 視覚的フィードバック

- ✅ 現在時刻を赤い縦線で表示
- ⚠️ 遅延タスクを赤枠で強調表示
- 🎨 ステータス別の色分け
